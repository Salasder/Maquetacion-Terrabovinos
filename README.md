 TERRABOVINO – Sistema de Gestión Ganadera
 Descripción del proyecto

TERRABOVINO es una plataforma web diseñada para facilitar la gestión y administración de las actividades ganaderas de una finca. Su propósito es centralizar la información del ganado y ofrecer herramientas que permitan llevar un mejor control de los procesos relacionados con la producción, sanidad, reproducción y manejo de los bovinos.

Además, la plataforma busca brindar contenido educativo para fortalecer los conocimientos de los usuarios sobre el sector ganadero.

 Objetivo general

Desarrollar una plataforma web que permita gestionar de manera organizada, sencilla e inteligente la información de una finca ganadera, facilitando el acceso a diferentes funcionalidades según el rol de cada usuario.

 Funcionalidades principales

Actualmente, el proyecto cuenta con las siguientes interfaces:

1. Página principal
Presentación de la plataforma TERRABOVINO.
Descripción de los servicios ofrecidos.
Acceso al inicio de sesión y registro.
Resumen de las funcionalidades del sistema.
2. Registro de usuarios
Formulario para crear una cuenta.
Registro de nombre completo y correo electrónico.
Creación de contraseña.
Registro opcional del nombre de la finca.
Selección del rol del usuario:
Ganadero.
Veterinario.
Trabajador.
Administrador.
Aceptación de términos y condiciones.
3. Inicio de sesión
Formulario de autenticación.
Ingreso mediante correo electrónico y contraseña.
Opción para recordar la sesión.
Enlace para recuperar la contraseña.
Acceso al formulario de registro.
4. Recuperación de contraseña
Ingreso del correo electrónico.
Interfaz para introducir un código de verificación.
Formulario para establecer una nueva contraseña.
Confirmación de la nueva contraseña.
5. Selección de roles

El sistema contempla cuatro tipos de usuarios:

Ganadero: gestiona el ganado, potreros, producción, reproducción y actividades comerciales.
Veterinario: administra información sanitaria, tratamientos, vacunas y reproducción.
Trabajador: consulta y registra las actividades diarias asignadas.
Administrador: gestiona usuarios, roles, permisos y configuraciones del sistema.
6. Módulos proyectados
Aprende: contenido educativo sobre ganadería.
Mi Ganado: registro y seguimiento de bovinos.
Sanidad: control de vacunas, enfermedades y tratamientos.
Reportes: consulta de información sobre producción, crecimiento, sanidad y reproducción.
Gestión de potreros: administración de espacios destinados al ganado.

🚀 Instalación y ejecución

Para visualizar el proyecto de manera local, sigue estos pasos:

Clona el repositorio:
bash
git clone URL_DE_TU_REPOSITORIO

Ingresa a la carpeta del proyecto:
bash
cd TERRABOVINO

Abre el archivo PagPrincipal.html en tu navegador web.

También puedes utilizar la extensión Live Server de Visual Studio Code para ejecutar el proyecto durante el desarrollo.
